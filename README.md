# Custom Auto Scroller

速度調整パネル付きの自動スクロールを行う Google Chrome 拡張機能です。
閲覧中のWebページを好みの速度で自動スクロールさせることができ、ハンズフリーでのブラウジングをサポートします。

## 主な機能

- **自動スクロールの開始・停止**: ショートカットキーまたは拡張機能のコマンドで切り替え可能です。
- **速度調整パネル**: スクロール中に画面右下に調整パネルが表示され、直感的に速度を変更できます。
- **画面スリープ防止（Display Keep-Awake）**: 自動スクロール中は `chrome.power` API によりディスプレイの自動消灯・スリープを防ぎ、ハンズフリーで読み続けられます。スクロール停止時やタブを閉じた際に自動で解除されます。
- **キーボードショートカット**: キーボードによる操作にも対応しています。
  - `Alt + S` : スクロールの開始 / 停止（トグル）
  - `ArrowUp` (↑) : スクロール速度アップ
  - `ArrowDown` (↓) : スクロール速度ダウン
  - `Escape` (Esc) : スクロール停止

## フォルダ構成

GitHubなどで管理しやすいよう、ソースコードとリソースを整理しています。

```text
auto-scroller/
├── README.md             # 本ドキュメント
└── src/                  # 拡張機能のソースコード
    ├── manifest.json     # 拡張機能の設定ファイル (Manifest V3)
    ├── background.js     # バックグラウンド処理 (ショートカットキー監視・スリープ制御)
    ├── content.js        # ページ制御・UI表示用のスクリプト
    ├── styles.css        # 速度調整パネルのスタイル
    └── icons/            # 各種サイズのアイコン画像
        ├── icon16.png
        ├── icon48.png
        └── icon128.png
```

## インストール方法（デベロッパーモードでの読み込み）

1. 本リポジトリをクローンするか、ZIPファイルでダウンロードして展開します。
2. Google Chrome を起動し、アドレスバーに `chrome://extensions/` を入力して拡張機能管理画面を開きます。
3. 画面右上の **「デベロッパーモード」** をオンにします。
4. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. 本プロジェクトの `src` フォルダを選択して読み込みます。

## 使い方

1. スクロールしたいWebページを開きます。
2. キーボードの `Alt + S` を押すか、拡張機能アイコンをクリックすると自動スクロールが開始されます。
3. 画面右下に表示されるパネルの `+` `-` ボタン、またはキーボードの `ArrowUp` `ArrowDown` でスクロール速度を微調整できます。
4. `STOP` ボタンをクリックするか、`Escape` キーまたは再度 `Alt + S` キーまたは拡張機能アイコンをクリックすることでスクロールを停止できます。
